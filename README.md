# Due Diligence Prep Bootcamp

Next.js App Router + TypeScript + Tailwind CSS + Framer Motion + Lucide React.

## Run

1. Extract the ZIP.
2. Open the folder containing `package.json` in VS Code.
3. Run `npm install` and `npm run dev`.
4. Open `http://localhost:3000`.
5. Run `npm run build` before publishing.

Each of the nine website sections has its own TSX component in `components/all-components/`. The main composition component is `components/ui/due-diligence-bootcamp.tsx`. Images are imported as modules from `src/assets/images/`. No demo content.

Public sharing requires deploying the app and enabling access. Importing a GitHub repo into AI Studio alone does not guarantee a public working link.
